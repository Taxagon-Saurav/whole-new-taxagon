# Taxagon Website

A production-ready Next.js, React, TypeScript, Tailwind CSS, and Framer Motion rebuild for Taxagon.

## Pages

- `/`
- `/about`
- `/services`
- `/contact`
- `/services/tax-advisory`
- `/services/tax-preparation`
- `/services/outsourced-cfo`
- `/services/company-formation`

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run check
npm run lint
npm run build
```
